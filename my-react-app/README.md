# React To-Do App

A simple React app that allows users to manage tasks with functionalities such as adding tasks, editing tasks, deleting tasks, and marking tasks as complete/incomplete.

## Features

- Add new tasks
- Edit existing tasks
- Toggle task completion
- Delete tasks
- Responsive design

## Clone the Repository

1. Open your terminal/command prompt.
2. Navigate to the directory where you want to clone the project.
3. Run the following command to clone the repository:

git clone https://github.com/anshaduk/ociuz-task.git

## Install Dependencies
Before running the project, you need to install the necessary dependencies.
npm install

##Running the Project
Once the dependencies are installed, you can start the development server by running:
npm start
